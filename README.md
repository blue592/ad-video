# 본과정 미션 2 · 10초야구소식

AI 생성 도구로 5~10초 광고 영상을 제작하고, 스토리보드에 장면별 프롬프트와 제작 과정을 기록하는 프로젝트입니다.

**10초야구소식**은 경기를 놓친 야구팬에게 KBO 10개 구단의 경기 결과와 선수 소식을 10초 영상이나 카드뉴스로 전하는 인스타그램 페이지입니다.

- **핵심 메시지:** 어제 야구 왜 난리였지? 10초면 알아.
- **캠페인 목표:** 전환 — 인스타그램 페이지 팔로우 유도
- **스토리라인:** 기승전결 · 퇴근길의 팬 → 마지막 타석의 긴장 → 끝내기 역전 → 팬의 반응과 팔로우 제안
- **기획 길이:** 10초 · 세로형 9:16 제작 제안 (최종 파일 실측 전)

## 7. 기록 및 관리 원칙

- 최신 스토리보드와 사용자 수정 지시를 기준으로 제작합니다.
- 대화·프롬프트 원문과 원본 이미지를 보존합니다. 공개 저장소에는 개인 정보 및 비공개 링크를 노출하지 않습니다.
- 작업 하나당 한 항목으로 기록하고, 실제 실행 날짜 및 시·분(KST)을 기준으로 전체 시간순 정렬합니다.
- 기획, 생성, 편집·통합, 최종 출력·검수의 실제 결과와 예정 작업을 구분합니다.
- 생성 횟수는 실제 실행 단위로 집계하며 단순 승인, 재첨부, 기록 호출은 생성 횟수에 포함하지 않습니다.
